# Contribution Guidelines

If you would like to contribute changes to this project, great!

Providing the project some *de minimis* changes implies that you are willing to have those changes be considered part of
the overall work, with copyright and licensing as denoted in the changed files. Supplying larger changes implies that
you are willing to have those changes be licensed the same way as the rest of the project, though your portions will
receive copyright indications.

From a process standpoint, the biggest thing is to **ask first before submitting a PR**. That could be by filing an
issue or by reaching out to the lead developer by some off-repository channel. PRs submitted without prior authorization
may be closed without further consideration.
